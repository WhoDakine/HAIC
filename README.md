The Marauder's submission for Hawaii Annual Innovation Challenge 2026

Using Python, we developed an AI-powered chatbot designed to help Hawaiʻi legislators identify relevant state and federal assistance programs for their districts. The application uses Ollama to run a local language model, while Streamlit provides the user interface. The chatbot integrates public government datasets into a SQL database to build district profiles and generate relevant program recommendations.

**Getting Started**

Click the link in the top-right corner to access the application:

https://whodakine.github.io/HAIC/

**Required User Information**

Before using the chatbot, you will be asked to provide the following information:

- **Name**
- **Legislative Chamber:** House or Senate
- **House/Senate District Number**
- **Position/Committee**
- **Policy Interests**

For fields requiring written responses, you may enter any relevant information. If a field does not apply, you may enter "N/A."

**Using the Chatbot**

When submitting a prompt, please allow the chatbot sufficient time to process your request.
The current version retrieves and analyzes substantial amounts of information from public government databases. It then evaluates the available information to identify and recommend potentially relevant assistance programs. As a result, some responses may take longer to generate.
